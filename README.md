# Socky1

**Collaborative sensory intelligence for specialty coffee roasters.**

A precision quality control web application designed for premium roasters working with grand cru beans. Socky1 works alongside Cropster as a collaboration and decision layer — shared cupping sessions, panel calibration, roast-curve-linked evaluation, and structured reporting.

## Key Features

- **Shared Cupping Sessions** — Real-time and async multi-user sensory evaluation
- **Remote Participation** — Guest access for tasters, buyers, and clients
- **SCA/CVA-Compatible Scoring** — Modern sensory forms aligned with current standards
- **Panel Calibration** — Track inter-cupper agreement, detect bias, improve consistency
- **Cropster Integration** — Link roast curves directly to cupping results
- **Smart Reports** — Internal QC views and client-facing presentation modes

## Getting Started

```bash
git clone <repo-url>
cd Socky1
```

Open `index.html` in a modern browser (once available).

## Tech Stack

- HTML5 / CSS3 / JavaScript (vanilla, browser-based)
- Designed for integration with the Cropster API
